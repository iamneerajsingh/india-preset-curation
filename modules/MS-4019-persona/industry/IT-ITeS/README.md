# IT-ITeS · Service delivery manager

Help a service delivery manager build a clear handover across India and global delivery teams.

## Persona and task

A manager needs an evidence-based view of unresolved tickets, escalations, and shift dependencies.

## Starter prompt journey

1. Group synthetic tickets and shift notes by issue and impact.
2. Create an escalation table with ticket references and missing information.
3. Draft an IST-based handover brief for the incoming team.

## Success and review

Do not invent resolutions or service commitments. Exclude credentials, client identifiers, and infrastructure secrets.
