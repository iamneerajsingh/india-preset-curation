# FSI · Branch operations lead

Help a branch operations lead prepare consistent, source-grounded staff guidance.

## Persona and task

A branch operations lead needs a quick reference for routine service questions and escalation routes.

## Starter prompt journey

1. Extract recurring questions from a fictional staff enquiry log.
2. Ground answers in a synthetic service FAQ with source sections.
3. Draft a team briefing and highlight questions needing authorised review.

## Success and review
