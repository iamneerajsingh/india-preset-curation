# MS-4019 persona

Start with the person behind the work: curate role-specific India scenarios, prompt journeys, and useful outcomes.

## Start with an audience

Browse the [persona-led India verticals](industry/README.md). Each starter pairs an industry with an example role. Replace or extend the role as your audience evolves.

## Persona curation canvas

| Question | Capture |
| --- | --- |
| Who is this for? | Role, responsibilities, and experience |
| What gets in the way? | A concrete task or workflow challenge |
| What context is needed? | Approved source material and constraints |
| What should change? | An observable, reviewable outcome |
| How will it be validated? | Success criteria and human reviewer |

## Add a persona use case

Copy the [use-case template](../../templates/use-case.md) into a vertical folder. Include the audience's language, approved demo data, prompt sequence, and review requirements.
