# MS-4019

Build a module-led collection of India-focused scenarios, reusable prompts, and demo assets across eight industry verticals.

## Start here

Browse the [India verticals](industry/README.md), choose an industry, and curate a use case from the [template](../../templates/use-case.md).

This is a workspace labelled MS-4019, not a reproduction of an official course. Add verified learning objectives, prerequisites, and authoritative course links when curating the module.

## Suggested curation flow

1. Define the business objective and audience.
2. Select a vertical and prepare synthetic demo assets.
3. Build a prompt sequence with explicit source context and output format.
4. Validate the output, document limitations, and record reviewer approval.
