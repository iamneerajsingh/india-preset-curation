# Gov

Curate public-sector communication scenarios using fictional service information.

## Starter use case: citizen service communication

Turn a synthetic service procedure into a plain-language citizen information sheet.

## Prompt direction

Extract eligibility, required documents, steps, and escalation routes from the supplied procedure. Mark missing information clearly.

## India lens

Validate regional-language versions with a human reviewer. Do not imply government endorsement or invent eligibility rules.

## Expected output and readiness

An accessible information sheet with source references. **Draft:** authorised source material and reviewer approval pending.
