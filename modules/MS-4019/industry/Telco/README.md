# Telco

Curate telecom service coordination and communication scenarios using fictional incidents.

## Starter use case: service incident communication

Turn a synthetic incident log into an internal briefing and a customer-facing status draft.

## Prompt direction

Separate confirmed impact, unknowns, actions, and the next update time. Do not invent restoration estimates.

## India lens

Review regional language and service-area descriptions. Exclude subscriber records, real network details, and operational secrets.

## Expected output and readiness

Two audience-specific update drafts. **Draft:** synthetic incident pack and communications approval pending.
