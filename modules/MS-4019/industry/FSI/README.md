# FSI

Curate financial-services scenarios with synthetic information and explicit human review.

## Starter use case: branch service knowledge

Use a fictional service FAQ to create a branch-team quick reference for common customer enquiries.

## Prompt direction

Create a question-and-answer guide grounded only in the supplied FAQ. Cite its sections and flag questions requiring escalation.

## India lens

Review terminology, language, and accessibility. Do not use real account information or provide financial advice or compliance assurances.

## Expected output and readiness

A reviewed service knowledge draft. **Draft:** source pack, compliance review, and owner validation pending.
