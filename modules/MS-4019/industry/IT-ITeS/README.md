# IT-ITeS

Curate IT services and service-desk scenarios for distributed India delivery teams.

## Starter use case: IT service desk handover

Use fictional tickets, a synthetic shift log, and a sample knowledge article to create the next shift's briefing.

## Prompt direction

Summarise unresolved tickets, group related issues, cite ticket IDs, and list next actions. Do not fabricate resolutions.

## India lens

Include IST-based handover timing and cross-region coordination. Remove customer identifiers, credentials, and infrastructure secrets.

## Expected output and readiness

A handover brief and escalation table. **Draft:** demo prompt pack, synthetic tickets, and validation pending.
